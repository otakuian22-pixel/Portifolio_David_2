Sobre

do zero à API

Sou otakuian22-pixel, desenvolvedor em formação com foco em back-end e lógica de programação. Meu percurso começa nos fundamentos de JavaScript e avança para a construção de APIs, servidores e interfaces web.

Os repositórios refletem essa evolução: exercícios de lógica, tarefas de aula de back-end, avaliações práticas, uma API de biblioteca, um front-end de cinema em HTML e o sistema e-classes, com times e competições para aulas de back-end.

Trabalho com JavaScript como linguagem principal, versionamento com Git e GitHub, e estou explorando o ecossistema de APIs REST, organização de código no servidor e interfaces limpas no front-end.
